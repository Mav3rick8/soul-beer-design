# Soul Beer: новый дизайн главной

Статическая версия главной страницы сайта Soul Beer Bar. Живая ссылка: https://mav3rick8.github.io/soul-beer-design/

- `docs/` — готовая статическая сборка, её отдаёт GitHub Pages.
- `source-src/`, `source-public/` и конфиги — исходники для пересборки (Next.js 14, Tailwind).
  Установка и сборка: `npm install` и `npm run build`, результат в `out/`.

Бронь, меню, заказ и админка работают только в полной версии сайта: им нужна база данных.
